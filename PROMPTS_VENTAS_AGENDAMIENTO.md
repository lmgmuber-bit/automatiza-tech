## 📞 PITCH PARA DIFERENTES SITUACIONES

### PROMPT 4.1: Ya tiene WhatsApp Business
```
Crea pitch de 2 párrafos que explique:
"Ya tienes WhatsApp Business, ¿por qué necesitas NUESTRO bot?"

Puntos a cubrir:
- WhatsApp Business = básico
- Nuestro bot = automático + IA
- Diferencias clave
- Beneficio adicional
- No sea arrogante

Tono: Educativo, no despectivo
Para cliente potencial: [TIPO_NEGOCIO]
```

### PROMPT 4.2: Ya usa un Sistema de Citas
```
Crea pitch que diga:
"Si ya tienes un sistema de citas, ¿por qué nuestro bot?"

Argumentos:
- Clientes prefieren WhatsApp
- No quieren entrar a web
- Bot en WhatsApp = donde están
- Integración con sistema actual
- Beneficio: +40% citas

Estructura:
1. Validar que su sistema es bueno
2. Pero...
3. El problema real es donde están los clientes
4. Solución: nuestro bot
5. Mantiene el sistema actual

Ejemplo con números realistas.
```

### PROMPT 4.3: Objeción "Es muy caro"
```
Crea contraargumento para "Es muy caro"

Estructura:
1. Validar que $[PRECIO] suena como gasto
2. Reframing: Es inversión, no gasto
3. Calcular ROI (cuántas citas = recuperar inversión)
4. Comparar con pérdidas actuales
5. Cierre: "¿Puedo mostrarte el cálculo?"

Datos:
- Precio del plan: $[X]/mes
- Precio promedio de cita: $[Y]
- Citas perdidas actuales: [Z]
- Conversión esperada: [W]%

Usa país: [PAÍS]
```

### PROMPT 4.4: Objeción "No entiendo de tecnología"
```
Crea pitch tranquilizador para cliente "no tech":

Puntos:
- No necesita entender
- Nosotros configuramos TODO
- Proceso simple (3 pasos)
- Soporte constante
- Sin código, sin tecnicismo

Ejemplo:
"Tu trabajo:
1. Conectas WhatsApp (1 click)
2. Nos dices servicios + precios
3. Listo.

Mi trabajo: El resto."

Usa analogía:
"Es como [COMPARACIÓN SIMPLE]"
```

### PROMPT 4.5: Objeción "Mis clientes son viejitos"
```
Crea argumento: "Si tus clientes usan WhatsApp, funciona"

Puntos:
- Viejitos/as usan WhatsApp (no descargan apps)
- Esperar 10 minutos = no pueden
- Respuesta al instante = felices
- No es complicado para ellos (es automatizado)
- Beneficio: Menos citas olvidadas

Ejemplo:
"Mi mamá de 65 años usa WhatsApp
pero ODIA descargar aplicaciones.
Si le envías link a web, se pierde.
Con bot en WhatsApp: Respuesta al instante. Feliz."

Tono: Empático, comprensivo
```
