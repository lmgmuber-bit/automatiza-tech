## 📌 TIPS PARA MEJORES RESULTADOS EN GEMINI

1. **Sube la imagen de TECH** como referencia — esto es CLAVE para que mantenga el diseño del robot.

2. **Si el texto sale mal** (Gemini a veces comete errores en texto), genera la imagen SIN texto y agrega el texto después en Canva o directamente en el HTML del sitio.

3. **Prompt sin texto** — Si prefieres solo la ilustración del robot + fondo para usar como background:
```
The TECH robot mascot standing on dark navy blue background with teal glow effects. Navy blue metallic body, teal accent lines, glowing cyan LED eyes, AT logo badge on chest, antenna, headphones. Friendly welcoming pose. Floating teal particles and subtle circuit patterns in background. Cinematic lighting, 4K, no text.
```

4. **Colores corporativos de referencia**:
   - Navy Blue: `#0a1628`, `#1e3a8a`, `#063f76`
   - Teal/Turquesa: `#06d6a0`, `#17b7b1`, `#10b981`
   - Naranja promo: `#ff6b35`, `#ff4500`
   - Púrpura Enterprise: `#c59cff`
   - Blanco: `#ffffff`

5. **Orden recomendado para probar**:
   - Banner 1 (Hero) → para la parte superior del sitio
   - Banner 3 (Canales) → para sección de servicios
   - Banner 4 (Urgencia) → para pop-ups o campañas
   - Banner 2 (Planes) → para sección pricing
   - Banner 5 (Stories) → para WhatsApp/Instagram
